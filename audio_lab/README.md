## 网页代选与自动记录（2026-10-12，当前操作方式）

启动根目录 `start_integrated.bat`，在向日葵当前题目启动联合流程。首轮完整 Input/A/B 或仅 A/B 播放后，后台开始分析；前台保留最多两次完整补听，随后按短听开关执行有限短听（默认六次）。结果就绪后取消尚未开始的补听/短听，对正在进行的补听及其自动连播核对播放图标后暂停，不必等整条连播结束才填评价；首轮完整录音不受此中断影响。补听预算用完但结果未出时等待分析，不无限循环点击。短听只轮换本题实际存在的播放器，无 Input 时不会点击 Input。

结果就绪后自动下滚读取评价。程序只给有结论、选项存在且确认未选择的维度代选，点击前再次核对画面，并在移开鼠标后连续两次确认选中状态。已有人选的项保留；不确定或点击未确认的项不反复点击。音质、发音忠实度、整体偏好目前仍需复核，不能为了填满页面而伪造结论；有 Input 时音色相似度、自然度可以按当前模型候选倾向代选。页面的六类评价（含自然度/整体偏好的 A/B 两选项和 Dominant Factor）都可读取，具体选项按当题画面识别。自动操作没有 Submit 点击路径。

你直接在远程页面选择或改答案即可，助手默认不显示重复填写表，只保留“补录或更正记录（可选）”备用。模型分析期间和代选之后都有独立只读观察线程；评价区布局稳定时复用行坐标，只检查按钮像素，不反复整页 OCR。选中需连续两帧一致，模糊状态不当成答案。按本机历史截图实测，缓存六行选中状态检查平均约 7 毫秒/帧（不含截图、轮询间隔、远程传输和首次 OCR）；完整识别延迟需现场测量。选项变化被看清后立即保存，不要求再点助手里的保存按钮。理由默认留空。

`comparison.json` 的 `remote_ratings` 保存网页选项、来源、识别时间、截图证据；`auto_actions` 记录代选前计划与点击后的确认。来源区分 `model_auto`（助手代选，尚未作为人工标签）、`human_remote`（从网页读到的人工选择/修改）和 `user_submit_confirmation`（观察到用户点击已启用的 Submit 后确认代选项）。最后一种记录明确标识看过模型，不冒充独立盲评。仅观察到点击不等于服务器提交成功，记录的 `server_success_verified` 为 false。若快速修改尚未看清就提交，未确认点击单独保留，不强行确认模型标签。灰色禁用 Submit 不作为人工确认。

人工结果优先，模型原判断保留；逐次人工修改继续存入 `feedback_history` 和统一 `feedback_library.jsonl`。即使没有理由，模型与人工有效答案的分歧也进入 `disagreement_cases`，等待后续跨题总结；不会自动编造分歧理由或训练模型权重。空白/取消选择标为需复核，不作为有效学习标签。题目编号变化、多个已选项同时重置或开始下一题时停止旧题观察，防止旧答案串题。远程窗口遮挡时只读观察等待恢复，不抢焦点；停止或 Esc 会结束本次自动操作/观察。

## 先验证录音

1. 双击 `setup_audio_lab.bat` 安装独立环境依赖（需网络，未自动执行）。
2. 双击 `start_audio_lab.bat`，选择实际播放向日葵声音的输出设备。
3. 选 Input，点开始录音，等“正在录”提示后手动播放完整 Input，结束后停止。
4. 分别录 A、B。为避免当前自动点击流程混入重听片段，首轮验证时先停用自动流程，手动播放。
5. 每次启动新建一个 sessions 目录，三个文件是 Input.wav、A.wav、B.wav，不覆盖已存在文件。也可以把已有 PCM16 WAV 按这三个名称放进同一目录。

录的是所选设备系统输出，不是麦克风，也不是仅向日葵进程。通知或其他播放器声音会混入。回听确认三段对应且完整；不能只看文件存在。最长录制 10 分钟，停止保存后记录采集信息。尚未现场确认音频设备兼容性。

## 生成独立报告

在本目录执行：

```
.venv\Scripts\python.exe analyze.py sessions\本题目录
```

输出 report.html 可回听三段，analysis.json 保留录音诊断和待人工填写的评价。诊断指标不等于音质评分。

有本地模型后可转写（程序不自动下载模型）：

```
.venv\Scripts\python.exe analyze.py sessions\本题目录 --model D:\Models\faster-whisper-model --device cuda --reference sessions\本题目录\target.txt
```

target.txt 应是页面指定朗读的正文。Input 通常是音色参考，其正文可能与 A/B 不同，不能直接拿 Input 的转写检查 A/B 是否漏词。ASR 自身也会识别错；词差异只作为人工检查线索，不自动认定发音错误。GPU 使用需要匹配的 CUDA/cuDNN 依赖，未在本机安装和实测；CPU 模式可先验证。

## 后续评价模型和验收

先积累至少 20 个有完整录音和你逐维度判断的样本，记录分歧原因。发音忠实度需结合目标文本和听音，音色相似度需使用独立说话人嵌入模型，音质需语音质量模型，自然度及整体偏好需单独验证。不要让文本模型只看转写就断言音色或自然度。

建议每条结果保存 task_id、三段音频路径、目标文本、真实维度/选项、模型版本、各维度证据、你给出的答案和模型答案；允许弃权。当前草稿维度是样例，不代表所有页面固定相同，接入时以页面当题维度为准。

验证顺序：三段对应完整 → 转写可核对 → 分维度建议与你比较 → 本地模拟勾选 → 人工确认后再接远程填写。最终接入也应单独通过结果文件交换，不改已冻结的点击版本。不得直接据此自动提交。

参考：SoundCard https://github.com/bastibe/SoundCard；faster-whisper https://github.com/SYSTRAN/faster-whisper 。
## 页面与录音同步实验

双击根目录 `start_paired_recording.bat`，选择实际的向日葵被控画面窗口，点击“开始同步录音与页面识别”，然后切回向日葵并播放完整 Input → A → B。结束后回到独立面板点击“结束并保存”。原点击程序不改动，可同时运行。

输出在 `audio_lab/sessions/paired_*`：`whole.wav` 为主控默认输出设备录音，`timeline.jsonl` 记录 Input/A/B 的播放图标、当前时间、总时长、未知状态以及相对录音时间，`screen/` 保留状态变化截图。仅观察可见画面，不接入 DOM，不产生鼠标输入；遮挡时保留未知状态，恢复后继续。

这版只建立对应证据，尚不自动切分、评分或提交。截图轮询与 OCR 存在耗时，音频时间原点根据首块采集完成时间估计，向日葵音画延迟尚未校准。短音频可能跨过整个识别周期；不能把未知区间认定为某段完整音频。录音最长10分钟，关闭面板也会请求保存。

## 联合助手自动恢复（2026-10-12）

根目录 `start_integrated.bat` 启动的联合助手标题为“自动恢复版”。以下只适用于联合流程，不改变上面的独立录音工具。

- 题型、播放器或计时未确认：重新读取并定位，最多额外两次；没有完整依据就不点击播放。
- 点击后四秒仍未观察到开始：重新观察，只有目标确认停止且处于起点/末尾时才补点，最多额外两次。若已延迟开始，继续观察，避免再次点击变成暂停。
- 首轮提前暂停、跳段、重播或录音切分证据不足：先对原画面的正文、播放器位置、可见题号和所有音频波形进行同题核对，再暂停、复位并重新完整录制一次。换题、失焦、Esc/停止不触发自动恢复。
- 模型启动前关闭录音并检查完整性；不合格录音不会进入模型评分。全零录音仍明确报告采集问题，点击重试无法修复声音路由。
- 重录保留原始失败文件在本题 `recovery_attempts/failed_1/`，记录 `failure.json`；新录音和时间线从新的采集原点开始，不拼接旧片段。主流程 `events.jsonl` 记录定位补试、播放补点、同题核对和重录结果。
- 评价漏点保留现有机制：确认空选后最多补点两次，并保护用户已经选择的答案。Submit 始终由用户点击。不会自动按 F5、切换下一题或关闭安全限制。

验证：184 项项目回归测试通过，包括真实轮询逻辑中的播放启动超时、延迟启动不误暂停、恢复次数上限、同文本不同波形拒绝重播、失败录音归档和人工接管。当前现场向日葵显示“无画面显示”，尚未完成这版在真实题目上的整轮验收；不能将测试通过视为远程现场已跑通。

### 人工操作与识别不清时的复查

联合助手“自动恢复·复查版”在自动输入前等待人工松开鼠标并停稳 1.2 秒。播放期间的读取不会等待鼠标停稳，录音与观察持续进行；未读清的状态按未知记录，不复用旧计时冒充新观察。图标/计时持续不清时反复读取新帧，连续 12 秒仍未恢复才交给首轮恢复机制。

单帧正文或标签异常会额外复查三帧，每次间隔 0.15 秒，全部不通过才报告页面变化；尺寸变化、失焦和 Esc 不套用此重试。人工抢先选中某个评价项只取消该项尚未按下的点击，其余项继续。鼠标移动后重新等停稳并两次核对，已选或明确人工清空的项目受保护，其他确认空选的项目仍可有限补点。每次复查、识别恢复和人工接管后重新核对都写入主流程事件日志。
