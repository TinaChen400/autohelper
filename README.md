# 向日葵播放助手：动态截图识别版

仅处理主控电脑上向日葵窗口显示的像素。OCR 和图像分析在本地运行，不读取网页 DOM，不连接被控浏览器。

## 启动

本项目已安装虚拟环境与依赖，双击 `start_assistant.bat`。另一台 Windows 电脑先安装 Python 3.10+，运行 `setup_assistant.bat` 安装依赖。安装需网络，识别运行不需网络。

## 连续流程（第一阶段）

关闭旧助手后重新启动，选择实际的向日葵远程窗口，把页面放在音频区，确保 Input/A/B 三个标题、播放按钮和时间都能看清。推荐放大向日葵窗口；不必为了观察助手而缩小远程画面。

界面新增“开始连续流程（本题）”，它与“开始实时识别”（只观察）不同：

1. 如果未播放，核对后自然点击 Input；已在播放时先观察剩余自动播放。启动时若已到 A/B，等剩余结束后会补听完整一轮，避免假装已观察到 Input。
2. 持续读取时间与图标，等待 Input→A→B 自动播放完成。页面必须保留三个播放器在视野内。
3. 默认额外重听 2～4 次，第一遍固定为 Input：首轮 B 实际结束后停顿约 1 秒，再自然移动并点击 Input。后续随机选 A/B，间隔 1～3 秒。重听再次触发连播时继续观察后续播放，避免抢播。
4. 用鼠标滚轮在被控内容区分段下滚，每段随机 1～3 格；边滚动边读取评价维度、说明和选项。
5. 看到 Submit、页面不再移动或达到最多滚动段数就停住。不会选择评价、提交或进入下一题。

可设置重听最少/最多次数（1～12，含第一遍 Input）、后续停顿最少/最多秒（0～15）、首轮 B 结束后停顿（默认 1 秒）、最多滚动段数（1～30）。停顿后还有自然移动和点击前核对耗时，不承诺恰好在第 1.000 秒按下。平滑鼠标运动带加减速、小幅曲线和点击停顿；随机性不用于评价选择。

每次用当前画面中的实际计时与图标确认结束，不使用 23/10/10 等固定音频时长。正常自动播放段间不再使用“等待下一段超时”或总时长加固定余量来终止流程；页面未切下一段时持续观察，可手动停止。计时持续看不清、提前暂停、进度卡住或手动接管的检查仍保留，不靠猜测启动重听。

移动鼠标、切换窗口、移动/缩放窗口、按 Esc 或助手停止按钮都会中止后续流程。停止不自动暂停已经播放的远程音频。

记录在本机 `artifacts/session_日期时间/`：播放开始/结束事件、点击目标、截图、读取的维度与停止原因。`dimensions.json` 中为 OCR 读取结果，未经模型评价；它不是已填写的答案。

当前下滚使用滚轮，不拖拽右侧滚动条。音频区未完整可见时不会自动搜索。计时文字太小、播放提前暂停、卡顿超过阈值、换题或布局变化时停止并提示。本阶段没有音频录制和评价模型。

## 先离线查看

点击“离线查看截图／视频”，选择 sample 内 MP4。工具读取视频约三分之一位置，标出标签与播放按钮，不操作桌面。绿色框是标签，橙色框是播放按钮。idle 表示播放三角，active 表示暂停双竖线。

## 实时使用

1. 打开被控页面，使参考音频标题、Response A/B 标题和按钮完整可见。
2. 在下拉框选择实际向日葵远程控制窗口。标题包含向日葵/AweSun/Sunlogin 的优先列出，设备名作为标题的窗口也可手动选择。
3. 点击“开始实时识别”。工具把目标窗口置于前台并观察，不点击播放。
4. 检查预览的标签与按钮对应关系。助手可与向日葵并排摆放，截图时不能遮住远程画面。
5. 点击“播放 Input/A/B 并验证”。工具运行两次 OCR 核对，点击前再次截图检查页面未变，然后点击一次。
6. 连续三次检测到对应按钮变成暂停图标才提示界面确认播放。8 秒超时不会重复点击。
7. “停止”取消后续操作；已开始的远程音频不会自动暂停。

不需要每道题手动标定按钮或采集图标样本。页面变化时重新定位，点击操作不使用缓存位置。

## 支持结构与限制

规则针对示例页面：参考音频上方有 Generate speech using this voice / Input speech / Input audio 标题；Response A/B 标题位于各自播放器上方；播放器左下是深色圆形按钮，白色播放三角或暂停双竖线。通过相对结构排除 Quick Replay 和评价区的同名文字。

- 可以只识别完整可见的一项，多个候选、OCR 低分或图标不明时拒绝点击。
- 文字长短引起区域移动、窗口移动或缩放时动态定位；标题被滚出画面时不能定位。
- 结构、主题、图标样式改变可能需要调整规则，不是通用网页识别器。
- 连续流程支持分段滚轮下滚；尚不自动搜索播放器、识别黑边边界、采集音频、评价或提交。
- 单次播放按钮确认暂停图标；连续流程结合时间与图标判断结束。均不确认声音实际到达，极短音频可能被漏观察并停止流程。
- 捕获可见屏幕，要求窗口不最小化、无遮挡。前台与多点遮挡检查不能保证发现全部小覆盖物。
- 不保证零误点，先用可重播音频验证当前真实页面。

## 速度与记录

OCR 输入最多 1280×900。页面变化或两秒刷新周期运行 OCR，其余循环跟踪局部图标，循环至少间隔 0.2 秒。点击前始终重新运行两次 OCR，并检查最新截图。

样本耗时与识别结果见 artifacts/recognition_report.json。样本第一帧 Input 图标受鼠标影响未返回目标，没有猜测。该小样本不能证明泛化准确率。

“保存当前识别结果”在本机 artifacts 内保存带框截图和 JSON。

## 程序与验证

- dynamic_app.py：当前界面与动态点击工作流。
- vision.py：本地 OCR、图标、区域关联与稳定检查。
- assistant.py：旧版手动标定工具；当前仅复用其窗口捕获 API。
- inspect_sample.py：离线识别示例截图，永不操作桌面。
- workflow.py：首轮自动播放、随机重听和滚动查看评价区。
- playback.py：时间 OCR 与播放完成状态机。
- human_mouse.py：自然鼠标动作、取消和手动接管检测。
- rating_reader.py：只读取评价维度、说明与可选项。

测试命令：`.venv\Scripts\python.exe -m unittest discover -s tests -v`。真实向日葵点击仍需首次现场验收。

## v0.13 自动寻找音频区

连续流程和单次播放在开始定位时，如果未确认全部 Input/A/B，会先分段向上滚动并重新识别，而不是首次失败就退出。没有任何播放器时每段上滚 3 格，附近已有播放器时上滚 1 格；三个播放器均确认后立即停止搜索并继续，支持首次播放的灰色锁定状态。搜索最多 30 段，连续两次上滚后画面不变时报告“可能已到顶部或滚轮未生效”，不声称已经确认顶部。该搜索仅用于启动定位，播放跟踪中布局变化仍需重新定位。停止按钮与 Esc 仍可取消。

## v0.11 开头随机短听

界面默认开启追加开头随机短听：完整重听后，先 Input、A、B 各一次，再随机轮换且不连续选择同一段，默认共 6 次。通过本地截图模板识别播放按钮右侧的圆圈重置键，确认停止且计时归零后再播放；不使用 DOM，不按未经确认的坐标点击重置键。

最短默认 0.4 秒、最长默认 1.2 秒。结合各段总长限制到最多一半，并留出至少 0.35 秒的暂停余量；如果无法同时满足下限和余量，就跳过并记录原因。开启播放后，以看到播放中图标作为计时参考，快速暂停；仍是近似按秒控制，不是逐音节识别，也不保证跳过开头静音。实际向日葵延迟未知，可能导致听到的片段超过目标，需现场验证。

“结束后下滚查看要求”可取消，取消后保持音频区域。短听日志包含目标时长、点击到看见播放中的延迟、点击到全部暂停的时间；这些是画面确认时间，不是真实音频延迟。自动播放触发其他段时也会尝试暂停，并确认全部停止才继续。重置图标未确认或归零未确认时跳过该次短听，不猜坐标。停止按钮和 Esc 可结束。

## v0.6 连续重听判定

启动时保存每段实际总时长；观察到该段开始后，以单调时钟和最近一次有效进度计算预计结束时间。时间文字暂时缺失时沿用本题已读时长，达到预计时间后仍需连续两次看到停止图标，才允许确认完成。下一段自动播放也可以确认已到预计结束时间的上一段完成。仅计时到点不会点击仍在播放的按钮。

首轮 B 确认结束后，按设置停顿（默认 1 秒）重播 Input，随后按重听次数随机重播 A/B，最后分段下滚查看要求。日志记录 player_durations、chain_completed、play_click 和 replay_completed，用于核实流程是否实际走到重复播放。离线测试覆盖时间文字持续缺失时完成重听并进入滚动；这不等于真实远程现场验收。

## 小尺寸远程画面修正

暂停图标先归一化后识别，支持缩小后只有一两个像素宽的竖线。Input 小字漏读时，会放大上方区域重新 OCR；仅参考音频的长标题允许有限错字，A/B 标签不模糊匹配。

开始观察和播放前会将鼠标移进被控内容区；点击后移到对应标签处，避免远程指针停留在播放按钮上。鼠标被遮挡的像素无法从截图恢复，仍不猜测。

状态栏“就绪（可播放）”表示三角图标，“播放中（暂停图标）”表示暂停图标。超时提示明确区分“已点击”和“未确认”，不等同于音频未播放。

tests/fixtures 内包含半尺寸视频帧和本次反馈截图的远程区域，供离线回归。小字重识别会增加 OCR 耗时；首次验收请关闭旧助手，再重新启动。
